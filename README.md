# Anniversary Edition – Website

## GitHub Pages

1. Neues GitHub-Repository erstellen, z. B. `anniversary-edition`.
2. Alle Dateien und den Ordner `images` in das Repository hochladen.
3. GitHub: **Settings → Pages**
4. Bei **Build and deployment** `Deploy from a branch` wählen.
5. Branch `main` und Ordner `/ (root)` auswählen.
6. Speichern. Nach dem Deployment stellt GitHub die Webseite unter der GitHub-Pages-Adresse bereit.

## Bilder austauschen

Die drei Platzhalter liegen in `images/`:

- `gothic1-wallpaper.svg`
- `gothic2-wallpaper.svg`
- `gothic3-wallpaper.svg`

Dann in `style.css` die jeweiligen Dateinamen bei den `background-image`-Einträgen anpassen.

## Download-Links

In `gothic1.html`, `gothic2.html` und `gothic3.html` befindet sich jeweils ein Platzhalter-Button. Dort kann später ein echter Download-Link eingetragen werden.
